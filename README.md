# Instagram Clone – Responsive Social Media Frontend

## 📌 Project Overview
Instagram Clone is a frontend web development project inspired by the Instagram social media platform. It provides a user interface similar to Instagram, featuring a sidebar navigation menu, stories section, posts feed, user suggestions, and a floating messages section.

The project is developed using HTML and CSS with Font Awesome icons to create a clean and attractive social media interface.

## 🚀 Features
- Instagram-inspired user interface.
- Sidebar navigation with Home, Search, Explore, Reels, Messages, Notifications, Create, and Profile.
- Stories section with profile images.
- Posts feed with images and captions.
- Like, comment, share, and bookmark icons.
- User profile information.
- Suggested accounts with Follow options.
- Floating Messages section.
- Hover effects and modern styling.
- Three-column layout.

## 🛠️ Technologies Used
- **HTML5** – Structure of the webpage.
- **CSS3** – Styling and layout design.
- **Font Awesome 6.7.2** – Icons for navigation and post actions.
- **CSS Flexbox** – Layout management.
- **External Images** – Profile pictures, stories, and posts.

## ⚙️ How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in VS Code.
3. Make sure `index.html` and `instagram.css` are in the same folder.
4. Open `index.html` in a web browser.
5. Explore the Instagram-inspired interface.

## 💻 Main Sections

1. **Sidebar:** Displays navigation options and Instagram logo.
2. **Stories:** Displays user profile images and story names.
3. **Posts Feed:** Displays posts, likes, captions, and comments.
4. **Right Sidebar:** Displays user profile and suggested accounts.
5. **Floating Messages:** Displays a messages section with profile images.

## ⚠️ Note
This project is a frontend design demonstration inspired by Instagram. It does not include actual user authentication, database connectivity, or backend functionality. Interactive features such as liking, following, and messaging are visual UI elements only.
